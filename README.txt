# Gede'Uffa Dictionary official website

Static website for GitHub Pages.

## Publish
1. Extract this ZIP.
2. In the GitHub repository `binyammichael1-cell/gedeuffa-dictionary`, upload `index.html`, `robots.txt`, `sitemap.xml`, and the entire `assets` folder to the repository root.
3. Commit the upload to the `main` branch.
4. Wait for GitHub Pages to deploy, then visit:
   https://binyammichael1-cell.github.io/gedeuffa-dictionary/
